                   Library Management System

## Project Description
The Library Management System is a SQL-based project designed to manage library records efficiently.

## Features
- Store book details
- Manage library records
- Insert book information
- View book records
- Retrieve stored data using SQL queries

## Technologies Used
- SQL
- SQL Server Management Studio (SSMS)

## Project Files
- `LibraryManagementSystem.sql` – SQL source code
- `README.md` – Project documentation
